# E-Commerce Website

Bem-vindo ao projeto **Onde Direction E-Commerce**! Esta é uma aplicação web desenvolvida para a disciplina de Programação WEB da Universidade Católica de Brasília, com a experiência de compra em uma loja virtual da banda One Direciton.
